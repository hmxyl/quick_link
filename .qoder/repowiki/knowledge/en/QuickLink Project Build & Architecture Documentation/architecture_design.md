This module is a single Markdown document (`BUILD.md`) that serves as the project's authoritative build and architecture guide. It defines a monorepo layout with separate `client/` (React 18 + TypeScript + Vite + Ant Design 5) and `server/` (Node.js + Express + TypeScript + Mongoose) subprojects, plus Docker Compose orchestration for MongoDB, server, and client containers. The backend follows a layered MVC pattern: controllers under `src/controllers/`, Mongoose models under `src/models/`, routes under `src/routes/`, middleware for auth/error handling, and business logic in `src/services/`. Data persistence uses MongoDB with schema migrations managed by `migrate-mongo` (scripts in `src/migrations/`, changelog tracked in a `migrations` collection). Security centers on bcrypt-hashed user passwords and AES-256-GCM encrypted account credentials derived from a master key via PBKDF2. The document also specifies REST API endpoints grouped by domain (auth, links, accounts, tags), index design, environment variables, and a phased development roadmap.
